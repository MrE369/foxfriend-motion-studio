Choose a color, tap geometry and expand to Connected part. Select another color to keep both regions visible. You can name each region. This is for inspection, not yet expression editing. B2.1/B3.1: tapping auto-expands connected geometry, and each color slot remembers its hit.

Isolate shows selected triangles, optionally with faded surroundings. Hide selected shows all other triangles. Restore all to select another surface. Selection and original geometry remain intact.

Handoff records a SHA-256 fingerprint of the original GLB, a mesh path, triangle indices, UVs when present, and 3D hit location. Import refuses a different file fingerprint. Original model data is never rewritten.

Scope and limitations

Milestone A includes universal inspection, triangle selection, connected-component selection using shared geometric edges, mesh selection, display modes, camera presets, and JSON save/restore. Large selections may be slow on phones. Connected parts are determined by matching position edges within a small tolerance, so near-coincident seams may connect or stay separate depending on geometry. This test hides or isolates selected source triangles in the viewer without editing GLB geometry; previews are rebuilt as lightweight meshes and may not follow animated/skinned deformation. Painting and geometry edits remain future milestones.

Character Paint Studio · integrated test

Same loaded model and camera. Select a UV-mapped single-material mesh, then paint on it. Original geometry stays untouched. Overlapping UVs and seams are not yet corrected. Painting is experimental in this unified build.

Painting requires UV coordinates. Paint JSON includes sampled 3D hit positions; textured GLB is a new export, never an overwrite. A brush stroke can affect overlapping UV islands.
